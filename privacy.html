智购甄选 隐私声明

更新日期：2026-10-01｜应用名称：智购甄选｜包名：com.zhgx.app

本应用为本地评论甄别与商品推荐工具。你使用应用即表示理解本声明；本应用不收集账号密码、身份证件、生物特征、精准位置或广告标识。首次启动会先展示本声明并取得明确同意，未同意不进入主流程。

数据处理清单

1. 京东联盟开放平台：当使用联盟商品数据源时，应用将搜索关键词、品类、预算、分页和排序参数，以及你配置的 appKey，通过 HTTPS 直连京东联盟开放平台。appSecret 经系统能力 HarmonyOS Asset Store Kit（华为提供的系统安全存储，属系统能力而非第三方 SDK）保存，仅在使用时读入内存构造签名，不写入普通配置文件。

2. 本地评论导入：你选择或粘贴评论文本后，应用解析商品、评论、作者行为与购买信息，并把结果保存到本机关系型数据库（S2 安全级别），用于刷单甄别和推荐。评论数据不上传到本应用运营方。

3. 本机配置：appKey、导入统计、种子数据标记、隐私同意状态、解锁状态和界面设置保存在本机 Preferences；appSecret 不保存在 Preferences。

4. 运行与诊断：本应用不集成第三方统计、广告、推送或埋点 SDK；数字商品购买使用系统能力 HarmonyOS IAP Kit（应用内支付，开发者：华为技术有限公司，属系统 Kit 而非第三方 SDK），详见第 6 条。不输出包含 appSecret 的日志。

应用内购买

5. 本应用提供一次性买断的「终身版」数字商品，实际名称和价格以下单时华为应用市场（IAP）展示为准。购买与支付由华为应用市场（IAP）完成，本应用不接触、不存储你的支付信息、银行卡号或账单地址。

6. 我们仅在本机保存「是否已解锁」这一状态标志，用于判断功能可用性；该标志不含任何支付信息。你可以通过应用内「恢复购买」查询或恢复该状态。

数据源与评论边界

7. 联盟数据源用于获取商品信息；当前评论分析使用你主动导入并保存在本机的评论，或内置演示数据。应用界面明确标识「联盟商品·本地评论」，不会把联盟商品数据源伪装成实时评论源。

一、系统能力（HarmonyOS Kit，由华为提供，非第三方 SDK）

  • ① HarmonyOS Asset Store Kit（资产存储·系统安全存储）｜开发者：华为技术有限公司｜性质：HarmonyOS 系统能力（非第三方 SDK）｜收集范围：仅在本机加密保存你配置的 appSecret（SyncType=NEVER，不同步上云）｜目的：为京东联盟请求签名提供本机凭据安全存储。
  • ② HarmonyOS IAP Kit（应用内支付）｜开发者：华为技术有限公司｜性质：HarmonyOS 系统 Kit（非第三方 SDK）｜收集范围：华为账号标识与订单信息，由华为侧处理；本应用仅接收已签名订单结果，不接触、不存储你的支付信息｜目的：数字商品购买与权益查询。

系统能力隐私政策（《华为消费者业务隐私声明》）：https://consumer.huawei.com/cn/privacy/privacy-policy/

二、第三方 SDK 清单（逐项明示：名称 / 开发者 / 收集范围 / 目的 / 隐私政策链接）

  • 京东联盟开放平台 API（京东联盟/京粉）｜开发者/运营方：北京京东叁佰陆拾度电子商务有限公司｜性质：第三方 SDK（可选启用）｜收集范围：搜索关键词、品类、预算、分页与排序参数、你自填的 appKey；不收集你的评论原文（评论仅存本机）｜目的：在你主动启用联盟数据源时获取商品数据。

第三方 SDK 隐私政策（《京东联盟/京粉隐私政策》）：https://jingfenapp.jd.com/static/html/about/privacyAgreement.html

除上述 1 项第三方 SDK 外，本应用不集成任何其它第三方 SDK（无第三方统计、广告、推送、埋点或支付 SDK）。

权限说明

  • ohos.permission.INTERNET：仅用于你启用联盟数据源时直连京东联盟开放平台，以及华为应用市场 IAP 服务所需的系统通信。

存储、共享与删除

本地评论和配置在你主动清空或卸载应用后按系统机制删除；appSecret 可通过重新配置覆盖。应用仅会将联盟商品搜索请求发送到京东联盟开放平台，不会把你导入的评论原文发送到网络。

如需了解京东联盟平台对请求数据的处理，请查看上方「第三方 SDK 清单」中给出的《京东联盟/京粉隐私政策》链接。
